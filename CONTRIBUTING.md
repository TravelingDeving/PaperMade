# Contributing

PaperMade is currently in private beta.

Bug reports and narrowly scoped pull requests are welcome once public contribution is enabled.

Before submitting code:

1. Do not include credentials, tokens, private links, or user data.
2. Keep paper-trading logic separate from real-money transaction execution.
3. Preserve the no-wallet/no-private-key trust model.
4. Document any new extension permission or host permission.
5. Keep shared P&L results clearly labeled as simulated/paper results.
